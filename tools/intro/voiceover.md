## 配音口径

- **语速**：比平时略快，约 5.2 字/秒。上面每段的字数都是按这个节奏配的。
- **重音**：落在「记不住」「看不见」「挪到模型外面」「四道闸」「逐项发钥匙」。
- **念数字**：「二十五个工具」念全，别念成「二十五 tool」。
- **不要念出**：`fail-closed`、`Markdown` 里的英文照常念，但 `INSTALL.md` 不用念。

## 合并配音

```bash
# 1. 配音存成 voice.wav（16kHz 以上，单声道即可）
# 2. 混进去，视频流直接复制不重新编码
ffmpeg -i intro.mp4 -i voice.wav \
  -c:v copy -c:a aac -b:a 128k -shortest intro-voice.mp4
```

旁白比画面短的话，`-shortest` 会让视频提前结束；想保全长就去掉 `-shortest`，
或在 `voice.wav` 后面补静音到 35.6 秒。
